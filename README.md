# BW Process Recap

半文（BW）品牌的可移植 Skill：把一次多步骤 AI 协作收成可复用的复盘文（Word / 飞书），重点记录目标偏移、颗粒度不对齐、纠正过程——这些也是大多数人会犯的错。

成稿必须遵守 Skill 内嵌的「半文去AI味写作与排版规则」（半文整理的反 AI 写作和排版要求）：自然段、少套话、不分号刷屏、不表演升华、不编造经历。
